# AGENTS.md — Home Stay Website
Website name is "Kashi Prangan" which is located in Varanasi so use ideas from there also on searching this website it should appear on top

## Goal
Build a modern, responsive, SEO-friendly informational homestay website in India using Next.js App Router and TypeScript. This repository is empty except for this file; create the app from scratch.

## Website Sections
Create a homepage with:
- Header, homestay name/logo placeholder, navigation, and mobile menu
- Hero section and property imagery
- About, rooms, gallery, amenities, location, nearby attractions, and guest information
- Contact section with phone, email, or WhatsApp placeholders
- Footer

if more sections are needed add them

Keep property content in a central typed data file where practical.

## Design
- Warm, welcoming hospitality style; mobile-first responsive layout
- Clear typography, spacing, and visual hierarchy
- Semantic HTML, keyboard accessibility, visible focus, sufficient contrast, and meaningful image alt text
- if required take reference from other websites but make it beautiful and elegant

## Technical Rules
- Use Next.js App Router, TypeScript, and Server Components by default.
- Use Client Components only when needed for interactivity.
- Use `next/image` where appropriate.
- Keep components maintainable and avoid unnecessary dependencies.
- Add page metadata, Open Graph metadata, and basic SEO; add sitemap/robots when appropriate.
- Document setup and run commands in `README.md`.
- Do not add a database, CMS, authentication, admin dashboard, API server, analytics, or third-party services unless requested.
- Never commit secrets or expose private values through public environment variables.

## Out of Scope
No booking engine, availability calendar, reservations, payments, guest accounts, or booking management. Contact and WhatsApp enquiry links are enough.

## Workflow
1. Inspect the repository and confirm it contains no app beyond this file.
2. Briefly propose the file structure and implementation plan.
3. Set up the Next.js app and build in focused phases.
4. Run available lint, type-check, tests, and production build; fix issues where possible.
5. Check responsive layouts, links, accessibility, and images.

Do not claim checks passed unless run. Do not commit, push, or deploy unless explicitly asked. Preserve user changes and avoid unrelated work.

## Definition of Done
The app builds, is responsive and reasonably accessible, uses accurate content or clear placeholders, includes basic SEO, and has no unrequested booking/payment functionality.
